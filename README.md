# Superstore Sales Dashboard — Excel

## Project Overview
An interactive Excel dashboard built to analyze sales, profit, product categories, regional performance, and monthly sales trends.

## Tools Used
- Microsoft Excel
- Data cleaning and validation
- PivotTables and PivotCharts
- KPI cards
- Interactive slicers

## Key Performance Indicators
- **Total Sales:** $2,297,200.86
- **Total Profit:** $286,397.02
- **Total Quantity Sold:** 37,873
- **Top Region by Sales:** West

## Dashboard Features
- Sales by Region
- Sales by Category
- Profit by Sub-Category
- Monthly Sales Trend
- Interactive filters for Region, Category, Year, and Sub-Category

## Key Insights
- The West region recorded the highest sales.
- Copiers had the highest profit among the displayed sub-categories.
- Tables recorded the largest loss among the displayed sub-categories.
- Monthly sales varied over time, with a prominent peak in 2017.

Download the Excel workbook and open it in Microsoft Excel. Use the slicers to filter the dashboard and explore sales performance.

This project demonstrates Excel skills in data analysis, business reporting, KPI tracking, and interactive dashboard development.
